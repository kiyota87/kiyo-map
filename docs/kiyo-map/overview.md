# きよた案件管理・アイディアマップ — 機能・今後の詳細まとめ（図解用）

図解スキルにそのまま渡せるよう、**現状（Done）** と **これから（Planned）** を分け、エンティティ・画面・フロー・優先度を明示しています。

---

## 0. プロダクト概要

| 項目 | 内容 |
|------|------|
| 正式名称 | きよた案件管理・アイディアマップ |
| 目的 | ふと思ったアイディアを拾い、案件として育て、完了まで見える化する個人向けワークスペース |
| 利用者 | Google ログインが許可されたメールアドレスのみ |
| 技術 | Next.js / React / TypeScript / shadcn / Tailwind / Auth.js / Gemini API |
| データ保存 | ユーザーごとのブラウザ localStorage（端末ローカル） |
| リポジトリ想定 | GitHub `kiyota87/kiyo-map` |

### コアバリュー（図の中心に置ける一文）

**入力（メモ）→ 整理（アイディア/案件）→ 実行（進捗）→ 完了（振り返り）→ 必要なら再開**

## 2. 案件マップのレイアウト（現状）

ヘッダーとフッターは全タブ共通。中央だけタブごとに変わる。

```
┌─────────────────────────────────────────────────────────┐
│ タイトル（左）              タブ（右）                    │  ← Header
├──────┬──────┬────────────────────┬──────────────────────┤
│ 大分類 │ 案件一覧 │ 詳細（最大幅）      │ 関連情報            │  ← Map only
│ 狭   │ 狭     │                    │                    │
├──────┴──────┴────────────────────┴──────────────────────┤
│ 💡 アイディア入力 ………… [保存]  [未整理]                    │  ← Footer
└─────────────────────────────────────────────────────────┘
```

| ペイン ID | 名称 | 幅方針 | 主な操作 |
|-----------|------|--------|----------|
| P1 | 大分類 | 固定・狭 | カテゴリ選択、件数表示、カテゴリ色 |
| P2 | 案件一覧 | 固定・狭 | 案件選択、アイディア時は AI ボタン |
| P3 | 詳細 | 最大（flex 大） | インライン編集、削除 |
| P4 | 関連情報 | 中 | 関連リンク、社内メモ、AIナレッジ枠 |

**案件マップに出る案件:** 進行中のみ（完了は S3 へ分離）

## 4. 機能一覧（現状 = Done）

図の「実装済み」レイヤー用。

### F1. 認証・アクセス制御

- Google SSO（Auth.js v5）
- `/kiyo-map/*` と `/api/kiyo-map/*` を保護
- `ALLOWED_EMAILS` で許可メール制限
- ログイン画面は kiyo-map 向け表示（タイトル・紫背景・黄ボタン）

### F2. 共通シェル

- タイトル「きよた案件管理・アイディアマップ」
- タブ: 案件マップ / 完了案件 / ダッシュボード
- 下部: アイディア入力バー
- 独自デザイン（ベース `#392171`、アクセント `#fed100`）

### F3. アイディア入力（クイックメモ）

- 保存 → status=`idea`、category=`アイディア`
- タイトル空、内容は memo のみ
- 一覧表示は「未入力」
- 詳細はメモ中心 + 「後から入力」欄

### F4. アイディアをかたちにする（AI）

- トリガー: 大分類「アイディア」選択時
- API: `POST /api/kiyo-map/shape-ideas`
- モデル: Gemini（`GOOGLE_API_KEY`）
- 出力: 候補案件、理由、推奨カテゴリ、次アクション、進め方
- 反映: 進行中へ移し、タイトル補完、履歴追加

### F5. 未整理メモ（手動）

- フッター「未整理」→ Sheet
- タイトル / カテゴリ / 状態 / 優先度を手入力して案件化
- AI 仮提案は未実装

### F6. 案件の閲覧・編集

- カテゴリフィルタ
- インライン編集（タイトル、進捗、締切、次アクション、状態、カテゴリ、優先度、メモ）
- 更新履歴の自動追記
- 進捗 100% または status=`done` → 完了扱い（マップから除外）
- 削除（確認ダイアログ）

### F7. 関連情報

- 関連案件リンク追加・遷移
- 社内メモ編集
- AIナレッジはプレースホルダのみ

### F8. 完了案件

- 完了一覧（完了日・カテゴリ・メモ）
- 「進行中に戻す」→ status=`in_progress`、マップへ遷移、該当案件をフォーカス

### F9. ダッシュボード（簡易）

- 今月完了件数
- 実行率（進行中 / アクティブ）
- アイディアストック件数
- アイディア一覧・進行中リスト
- グラフ・月次・レポートは未実装

### F10. カテゴリ色分け

- 大分類ナビ（左ボーダー・ドット・件数）
- 案件一覧ドット（締切近いと赤リング）
- 詳細・完了・AI提案のカテゴリバッジ

## 5. 主要ユーザーフロー（現状）

図解スキル向けのフロー定義。

### Flow A: アイディアを拾う

```
ユーザーがフッターに入力
  → 保存
  → Project(status=idea, title="", memo=入力文)
  → 案件マップの「アイディア」に表示（タイトル「未入力」）
  → 詳細はメモ中心
```

### Flow B: アイディアを案件にする（AI）

```
大分類「アイディア」選択
  → 「アイディアをかたちにしよう」
  → Gemini API
  → 提案カード表示
  → 「この案で進める」
  → status=in_progress、category=提案カテゴリ、title補完
  → 通常案件として編集可能
```

### Flow C: 案件を進める

```
案件選択
  → 詳細で進捗・次アクション等を更新
  → history に追記
  → progress=100 or status=done
  → マップから消え、完了案件タブへ
```

### Flow D: 完了から再開

```
完了案件タブ
  → 「進行中に戻す」
  → status=in_progress、completedAt=null
  → 案件マップへ遷移し該当案件を選択
```

### Flow E: 未整理から案件化（手動）

```
未整理ボタン
  → Inbox 一覧
  → 手入力でカテゴリ等を指定
  → Project 作成、Inbox resolved
```

## 7. 状態遷移図（案件ライフサイクル）

図解の中心にしやすい。

```
        [クイックメモ]
              │
              ▼
         ┌────────┐
         │  idea  │ ← タイトル未入力可（メモのみ）
         └───┬────┘
             │ AIかたちにする / 手動で状態変更
             ▼
      ┌─────────────┐
      │ in_progress │ ←── 「進行中に戻す」（完了案件から）
      └──────┬──────┘
             │ 保留に変更
             ▼
         ┌─────────┐
         │ on_hold │
         └────┬────┘
              │ 再開 or 完了
              ▼
         ┌──────┐
         │ done │  progress≥100 でも done 扱い
         └──────┘
              │
              └── 表示場所: 完了案件タブ（マップには出ない）
```

削除はどの状態からでも可能（確認ダイアログ後、関連リンクからも除去）。

## 10. 一文サマリー（スライド1枚用）

**現状:** Google ログイン後、アイディアをメモし、4ペインで案件を編集し、完了タブで振り返り・再開できる。AI は Gemini による「アイディアをかたちにする」まで。デザインは紫ベース＋黄アクセントとカテゴリ色分け済み。

**これから:** 未整理の AI 振り分けとダッシュボード可視化で「入力〜振り返り」を完成させ、月次トピックス・きよたほさ・DB 永続化へ広げる。
